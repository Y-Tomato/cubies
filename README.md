# 俄罗斯方块 · Tetris

一个纯 HTML/CSS/JavaScript 实现的俄罗斯方块游戏，单文件即可运行，无需任何依赖。

## 在线游玩

直接双击打开 `index.html`，或在浏览器中打开即可开始游戏。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| ← / → | 左右移动 |
| ↓ | 软降（加速下落） |
| ↑ / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 硬降（直接落底） |
| C | 暂存方块（Hold） |
| P | 暂停 / 继续 |
| R | 重新开始 |

## 特性

- 7 种经典方块 + 标准配色
- 7-bag 随机序列，保证方块均匀
- 幽灵方块（落点预览）
- 暂存（Hold）功能
- 下一个方块预览（3 个）
- 消行计分、等级加速、最高分记录（本地存储）
- 响应式布局，移动端触屏按钮
