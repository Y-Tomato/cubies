# 俄罗斯方块 · Tetris

一个纯 HTML/CSS/JavaScript 实现的俄罗斯方块游戏，单文件即可运行，无需任何依赖。

## 在线游玩

直接双击打开 `index.html`，或在浏览器中打开即可开始游戏。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| ← / → | 左右移动 |
| ↓ | 软降（加速下落） |
| ↑ / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 硬降（直接落底） |
| C | 暂存方块（Hold） |
| P | 暂停 / 继续 |
| R | 重新开始 |

## 特性

- 7 种经典方块 + 标准配色
- 7-bag 随机序列，保证方块均匀
- 幽灵方块（落点预览）
- 暂存（Hold）功能
- 下一个方块预览（3 个）
- 消行计分、等级加速、最高分记录（本地存储）
- 消行闪烁特效（整行白闪后消失）
- 原创 8-bit 背景音乐 + 音效（Web Audio API 实时合成，无需外部文件）
- 静音开关（侧栏「音效」按钮）
- 移动端全屏适配（手机 / 微信内置浏览器 / 小程序 web-view）：棋盘随屏幕自适应缩放，一屏内完整显示，底部双拇指触控按钮，适配安全区与横竖屏

## 移动端 / 微信使用

- 手机浏览器或微信中直接打开本页即可：棋盘会自动缩放到合适大小，无需滚动即可看到完整画面并用底部按钮操作。
- 若在小程序内运行：用 `<web-view>` 组件加载本页的 HTTPS 地址即可（需在公众号后台配置业务域名）。
