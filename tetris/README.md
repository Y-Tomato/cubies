# 俄罗斯方块（微信小程序）

一个适配 **移动端** 与 **PC 端** 微信小程序的俄罗斯方块游戏，包含消行特效、背景音乐与音效。

## 功能特性

- 🧩 **经典玩法**：七种方块（I/O/T/S/Z/J/L）、7-bag 随机、软降/硬降、旋转、暂存、幽灵投影
- 💥 **消行特效**：整行闪烁后一次性消除，多行同消正确处理
- 📈 **计分与等级**：分数 / 等级 / 消行数，等级提升重力加快
- 🏆 **最高分纪录**：本地持久化存储
- 📱💻 **自适应布局**：根据窗口尺寸自动计算格子大小，手机竖屏与 PC 窗口均可正常游玩
- 🎮 **触屏按钮**：方向、旋转、硬降、暂存，长按方向键可连续移动
- 🔊 **音效**：旋转、消行、硬降、暂存、升级、游戏结束等反馈
- 🎵 **背景音乐**：循环播放 8-bit 旋律，可独立开关

## 运行方式

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具 → 导入项目 → 选择本项目根目录
3. 将 `project.config.json` 中的 `appid` 改为你自己的小程序 AppID（当前为 `touristappid` 游客模式，仅用于本地预览）
4. 编译运行即可

## 目录结构

```
.
├── app.js / app.json / app.wxss     # 全局配置与样式
├── project.config.json              # 微信开发者工具项目配置
├── sitemap.json
├── audio/                           # 音效与背景音乐（WAV）
│   ├── click.wav  clear.wav  drop.wav  rotate.wav
│   ├── hold.wav  level.wav  over.wav  bgm.wav
├── utils/
│   ├── engine.js                    # 俄罗斯方块核心逻辑
│   └── audio.js                     # 音频管理
├── pages/
│   ├── index/                       # 菜单页（开始、音效开关、操作说明）
│   └── game/                        # 游戏页（Canvas 渲染）
└── tools/
    └── gen-audio.js                 # 音频资源生成脚本
```

## 重新生成音频

音频文件由脚本合成，无需外部素材。如需重新生成：

```bash
node tools/gen-audio.js
```

|------|------|
| ◀ / ▶ | 左右移动 |

| ↻ | 旋转 |
| ⤓ | 硬降 |
| H | 暂存 |

| 顶部 🔊 / 🔇 | 背景音乐开关 |
